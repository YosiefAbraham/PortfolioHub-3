# Gallery Images

This directory contains images displayed on the Gallery page (`/gallery`).

## Adding Images

To add images to your gallery:

1. Place your image files (JPG, PNG, GIF, WebP, SVG) in this directory
2. Images will automatically appear on the gallery page
3. The gallery uses a Flickr-style masonry layout that adjusts to different screen sizes

## Naming Convention

Images will use their filename (without extension) as the alt text, with hyphens and underscores converted to spaces.

Example:
- `summer-vacation-2024.jpg` → Alt text: "summer vacation 2024"
- `my_photo.png` → Alt text: "my photo"

## Recommended Image Specs

- **Format**: JPG or PNG preferred
- **Size**: Under 2MB for optimal performance
- **Resolution**: At least 1200px on the longest side for quality display

## Example

Simply drag and drop or copy your images into this folder, and they'll appear on your gallery page!
