## Technical Details:

- **Format**: SVG (Scalable Vector Graphics)
- **Dimensions**: 400x400px viewBox
- **Background**: Transparent
- **Style**: Simplified cartoon/illustrated style
- **Compatibility**: Works across all modern browsers
- **File Size**: Small and optimized for web

## Usage in Code:

These logos are referenced in `ExperienceSection.tsx` in the `additionalExperiences` array:

```typescript
logo: "/images/logos/stanford-black-rhythm-sound.svg";
```

The ExperienceCard component will display these logos when available, falling back to initials if not found.

## Design Philosophy:

Each logo is designed to be:

1. **Recognizable**: Clearly represents the organization's identity
2. **Clean**: Simple, uncluttered design that works at various sizes
3. **Professional**: Appropriate for a portfolio context
4. **Cohesive**: Similar illustration style across all logos
5. **Brand-appropriate**: Uses colors and symbols associated with each organization
